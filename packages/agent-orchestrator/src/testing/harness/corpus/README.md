# Frozen Phase A corpus

`phase-a.json` is the DJ-approved, label-locked Slice A0 corpus. It contains the eight selected
production-derived requests, their expected route and reason code, their shared snapshot reference,
and their machine-checkable acceptance checks.

Do not edit this corpus in place after prompt work begins. Corrections require a new corpus version
and a recorded rationale so route labels cannot drift toward observed model behavior.
