# Agentic Chat failure scenarios

- **Last reviewed:** 2026-11-17
- **Status:** Reference index
- **Scope:** The 53 scenarios from the former Phase 5 test-source audit

Use this index to find the tests that exercise failure behavior. The old audit only searched
for these strings in test files; it could pass with a skipped test or an assertion removed.
It has been replaced by this reference so renaming a test does not break the worker suite.
The owning behavioral and SQL tests remain unchanged.

All referenced files and search hints existed when this index was moved. That check is not
proof that the tests execute or pass. Use [the runner guide](./README.md) for execution
ownership and distinguish historical SQL fixtures from current-schema contracts. Search hints
are navigation aids, not frozen test names.
