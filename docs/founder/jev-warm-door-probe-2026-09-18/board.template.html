How to read it

What Jev judged

Each business was sent as a sourced record with the offer and asked eight yes/no or 0–3 questions about the evidence. No forecasts. Two typed picks: revenue band and which entry point the evidence supports.

What the score is

A weighted sum in code, times a drive-time factor (≤25 min ×1, ≤35 ×0.85, else ×0.6). The warm path column is flat for now: you have no memberships yet, so veteran-owned businesses score "both veterans" and the rest score nothing. Joining one room changes it.

What to do with it

Set a status when you visit or call. It saves to this page. Those outcomes are the only real test of whether the order was right, so log the misses too.

The list

Green cells are strong evidence. Amber tag = hiring an estimator or ops manager right now. Red tag = Marine-owned. Grey tag = from the beachhead board. Open a row for the sourced evidence and the owner's name.

Walk-in routes

Grouped by drive time from Glen Burnie, best score first. A route is a day, not a list: pick one, put a date on it.
