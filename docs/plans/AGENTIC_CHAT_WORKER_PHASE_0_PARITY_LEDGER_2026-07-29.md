# Agentic Chat Worker Migration: Phase 0 Parity Ledger

**Date:** 2026-07-29

**Status:** Local ledger and legacy proving fixtures complete; target preflight captured 2026-07-30 (hazard probes all zero); first exact-tree hosted battery retained. Corrected three-run timing/persistence cohort and final audit re-acceptance of contract revision .5 pending.

**Parent plan:** `docs/plans/AGENTIC_CHAT_WORKER_REALTIME_MIGRATION_PLAN_2026-07-29.md`

## Purpose

This ledger prevents the worker migration from treating the current model loop as the whole product. The live route owns authentication, session and context resolution, prepared inputs, history, attachments, tools, quality safeguards, persistence, cancellation, telemetry, and finalization in addition to calling `streamFastChat`.

Each row names the current owner, the intended target boundary, and the test that must prove parity. `Covered` means a current local regression test exists; it does not mean the worker adapter exists. `Gap` means the current behavior or test is insufficient for the worker contract.
