# /privacy claims → the code that makes them true

Every sentence on `apps/web/src/routes/privacy/+page.svelte` (version 2026-09-24) maps to a row here.
If you change a claim, change this file in the same commit and bump `CURRENT_PRIVACY_VERSION`
(`apps/web/src/lib/legal/policy-versions.ts`). If you change code that a row cites, check the claim
still holds. The full store-by-store map is in [DATA_INVENTORY.md](DATA_INVENTORY.md). The audit
behind both files is tasker 103.

**True-on-deploy conditions.** The page is true only once all of the following ship together:

1. **Migrations applied in this order:**
    - `20260924190000_privacy_retention`
    - `20260924190100_account_deletion_completeness`
    - `20260924190110_libri_account_deletion_purge`
    - `20260924190200_redact_stored_pass_through_tool_results`
    - `20260924190250_user_data_export_queue_type` (enum value; its own transaction)
    - `20260924190300_user_data_panel_and_exports`
    - `20260924190350_task_archive_state` (backfills every soft-deleted task as archived; must precede the purge)
    - `20260924190400_purge_soft_deleted_items`
    - `20260924190500_calendar_analysis_minimal_events`
    - `20260924190600_privacy_gaps` (brain-dump delete, notification/webhook retention; must precede the web and worker deploy)
2. **Worker and web deployed from the same commit, right after the migrations** (chat delete calls a new
   RPC). Then re-run the `190350` backfill statement once (idempotent), so tasks archived by the old web
   code during the gap are kept as archived, before the worker's first nightly purge (03:30).
3. **Env vars.** Vercel needs `PRIVATE_POSTHOG_PERSONAL_API_KEY` and `PRIVATE_POSTHOG_PROJECT_ID`
   (row D6). Railway's `AGENTIC_CHAT_REVIEWER_MODEL` must be unset or `openai/gpt-5.6-luna` (row A3).

Rows marked **ENV** or **MANUAL** depend on a setting outside the repo.

Line numbers drift. The symbol names are the stable reference.
