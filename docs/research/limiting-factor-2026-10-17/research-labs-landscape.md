## (b) The most important dated facts

1. **OpenAI killed its proactive brief, then re-shipped the idea as a paid "agent persona."** Pulse (Sept 2025 → Pro only, never reached Plus) was sunset **2026-06-17** with "use scheduled tasks." On **2026-09-29** Altman introduced Dots: "always-on, proactive agents" you name and customize; one free on Pro/Business Premium, extras paid; conversations with a Dot don't count against ChatGPT limits ([Engadget liveblog](https://www.engadget.com/2271985/openai-dev-day-live-blog-chatgpt-news/)). Altman on Every (**2026-09-30**): "I trust my dot to have good judgment about what I need to think about and what I don't… it's definitely going to take some time to smooth it all out" ([transcript](https://every.to/podcast/transcript-how-sam-altman-uses-dots-to-take-back-his-time)). Early hands-ons: slow, glitchy, memory-limited, "Your Chief of Staff is Still an Intern" ([metedata](https://metedata.substack.com/p/chatgpt-dot-review-your-chief-of), [geeky-gadgets](https://www.geeky-gadgets.com/chatgpt-dots-review-24-hours/)).

2. **OpenAI went vertical into productivity software in Q3 2026.** ChatGPT Work (**2026-07-09**, GPT-5.6, "take action across your apps and files, stay with a project for hours"; Codex desktop merged into ChatGPT desktop; shares an agent usage pool) ([Techzine](https://www.techzine.eu/news/applications/142807/chatgpt-work-openai-turns-a-chatbot-into-an-autonomous-worker/)). ChatGPT Space + Pages (**2026-09-29**): "Your pages and files all live together in Space, like they would in a drive" — Altman; Slides/Sheets "coming soon"; Space replaces Library, does NOT replace Projects; absent from Free/Go/Plus ([TechCrunch](https://techcrunch.com/2026/09/29/openai-takes-on-microsoft-with-the-launch-of-what-feels-a-whole-lot-like-chatgpts-own-office-suite/), [eesel](https://www.eesel.ai/blog/chatgpt-space)). Altman: "We didn't set out wanting to do this… software was really not designed, on the whole, for collaborating with AI."

3. **Anthropic's "project" story is real but gated to developers.** Cowork GA **2026-04-09**; scheduled tasks **2026-02-25**, device-offline since **2026-07-07**; memory unified chat+Cowork **2026-08-25**; Projects redesign **2026-09-17** (coordinator + threads + shared memory + library) is Claude Code cloud-sessions only, select Pro/Max, waitlist, "as the rollout expands to chat and Cowork" ([claude.com](https://claude.com/resources/articles/projects-redesigned)). Routines remain a research preview with no approval step for connector writes ([docs](https://code.claude.com/docs/en/routines)). Verticals: Claude for Small Business **2026-05-13** (15 workflows, "you approve before anything sends, posts, or pays"), Financial Services agents May 2026, Government Oct 2026. Run-rate **$65B end-July 2026** ([CNBC 2026-08-17](https://www.cnbc.com/2026/08/17/anthropic-says-annualized-revenue-climbed-to-65-billion-in-july.html)).

4. **Microsoft licensed Anthropic's Cowork instead of building its own.** Copilot Cowork (research preview **2026-03-09**, GA **2026-06-16**) runs on Opus 4.8/Sonnet 4.6, billed via Copilot Credits ($0.01), ">half of the Fortune 500" using it ([MS blog](https://www.microsoft.com/en-us/microsoft-365/blog/2026/06/16/copilot-cowork-is-now-generally-available/)). Copilot Notebooks became a "persistent AI workspace" **2026-09-23**; Planner Agent widened **2026-08-11**.

5. **Google's always-on agent is consumer-first, memory is enterprise-first, and neither has a project model.** Spark (**2026-05-19**, AI Ultra beta → AI Pro) was folded into a "Task" mode with a Scheduled page on **2026-10-12**; Personal Intelligence (**2026-01-14**) excludes Workspace accounts; NotebookLM renamed Gemini Notebook **2026-07-16**; enterprise "Gemini agent" (**2026-10-08**) with 4 memory types is private preview, no price/GA ([9to5Google](https://9to5google.com/2026/10/08/gemini-agent-google-cloud/)). Five cross-app agentic Workspace features shipped **2026-09-09** ([Workspace blog](https://workspace.google.com/blog/product-announcements/less-switching-more-flow-5-new-agentic-capabilities-across-google-workspace-apps)).

6. **Notion is the incumbent that actually shipped "proactive per-workspace agents."** Custom Agents **2026-02-24** (autonomous, schedule or trigger, MCP to Slack/Linear/Figma/HubSpot, logged + reversible), free until **2026-05-03**, then credits for Business/Enterprise only ([notion.com](https://www.notion.com/releases/2026-02-24)). 3.6 External Agents (Claude, Cursor) **2026-07-01**; 3.7 skills library + sub-agents + Agent SDK **2026-09-15**; 3.8 Oct 2026. Agent memory is still "a designated page of standing instructions," not learned project state.

7. **Memory reliability is the labs' open wound (see §7).** OpenAI forum Sept–Oct 2026: "ChatGPT almost never remembers anything said in other Chats, even those in the same Project… forgets stuff we talked about a week earlier, in the same Chat" ([community](https://community.openai.com/t/chatgpt-recalls-saved-memory-but-fails-to-apply-it-and-invents-plausible-context-instead-of-verifying-history/1393739/2)); "Chat Memory Full" with no published cap. Claude Code: compaction silently drops project instructions ([golev](https://golev.com/post/claude-saves-tokens-forgets-everything/)). Microsoft added memory citations **2026-10-14** precisely because users couldn't see what shaped answers.

8. **The product graveyard grew fast.** Agent mode retired (Jul/Aug 2026 → Work), Atlas browser shut **2026-08-09**, Canvas dropped from GPT-5.5 models **2026-05-28**, app directory → plugin directory **2026-07-09**, Library → Space. Limitless sold to Meta **2025-12-05** (pendant sales ended, Rewind wound down, EU/UK withdrawn, [TechCrunch](https://www.techcrunch.com/2025/12/05/meta-acquires-ai-device-startup-limitless/)).

## (c) What the labs have NOT shipped, or have killed (with evidence)

**OpenAI**

- Pulse: KILLED 2026-06-17 (X post). Never expanded beyond Pro.
- ChatGPT agent mode: retired (help center says unavailable → use Work; date July 9 or early Aug 2026 per [usecarly](https://www.usecarly.com/blog/chatgpt-agent-mode/), [aitechsafar](https://www.aitechsafar.com/2026/08/chatgpt-work-what-happened-to-agent-mode-2026.html)). Operator folded earlier.
- Atlas browser: shut 2026-08-09 ([9to5Mac](https://9to5mac.com/2026/08/04/openai-explains-what-will-happen-when-chatgpt-atlas-shuts-down-this-weekend/)); Windows/iOS/Android builds never shipped.
- Canvas: removed from GPT-5.5 Instant/Thinking 2026-05-28; replaced by inline writing/code blocks ([OpenAI canvas notes](https://help.openai.com/en/articles/9624314-chatgpt-canvas) via search).
- NOT shipped: a native task/project tracker; Space for Free/Go/Plus; "Keep updated" self-updating pages (not at launch); collaborative Slides/Sheets ("coming soon"); Dot texting; Dots in EEA/CH/UK; more than one Dot per user; ChatGPT Work inside project-only-memory projects (support: no timeline); a published memory capacity; any per-write receipt/ledger.
- Scheduled tasks: tasks can only notify/produce output inside ChatGPT; sources conflict on whether they can take external actions (UNVERIFIED).

**Anthropic**

- NOT shipped: a proactive daily brief product (Reflect is a monthly recap); a native task manager; Projects redesign in chat/Cowork (Claude Code only, waitlist); shared/team routines (individual account only); approval gates in Routines (explicitly none); Cowork scheduled tasks with event triggers (schedule/manual only); an official cross-agent skills marketplace (community-run; "claude skills" search interest down ~62% since Jan 2026 peak, [dev.to](https://dev.to/skillgild/the-state-of-claude-skills-in-2026-what-38000-searches-say-248n), UNVERIFIED).
- Claude Code excluded from unified memory (2026-08-25).

**Google**

- Workspace Flows (announced Apr 2025) never shipped under that name; absorbed into Workspace Studio GA 2025-12-03.
- Personal Intelligence: not for Workspace accounts. Spark: paid only, US only, Android-first redesign. Scheduled actions capped at 10. Enterprise Gemini agent: no price, no GA date. No "project" object anywhere in Gemini.

**Microsoft**

## What this means for BuildOS (one screen)

- **The exact BuildOS primitive — a durable, structured project object that an agent reads/writes and proactively works from — is still not shipped as a mainstream feature by any lab.** OpenAI killed its daily brief and replaced it with a $100+/mo persona; Anthropic's project memory is a dev-only beta; Google has no project object; Microsoft needs an enterprise seat; Notion has the closest thing (Custom Agents) but memory is a hand-written instructions page and it's Business/Enterprise-only.
- **What the labs did ship is the engine, not the car:** always-on agents (Dots, Spark, Grok Bot, Cowork), scheduled/triggered runs, connector writes (calendar now writable in all four), and app/plugin surfaces (ChatGPT plugin extensions + Sign in with ChatGPT; Claude developer portal; Notion External Agents). All four explicitly invite third-party "whole workspace" plugins.
- **Approval gates/receipts are inconsistent everywhere** (Routines: none; Work: model auto-review; Cowork: approve sensitive actions; Notion: logged after the fact). A receipt-per-write ledger is still differentiation.
- **Memory is the labs' public failure mode** (OpenAI forum Sept–Oct 2026; Dots "intern" reviews; compaction). "Structure beats chat memory" is a defensible, currently-true claim — with the caveat that OpenAI Space/Pages and Anthropic's Projects redesign are both aimed at the same gap and shipped within the last 30 days.
- **Price umbrella:** the proactive-agent tier is $100–$500/mo (ChatGPT Pro/Business Premium, Claude Max, Google AI Ultra, Grok Bot). Free/Go/Plus ChatGPT users get no Space, no Dot.
