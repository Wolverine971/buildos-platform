## Remedy alternatives and discriminating experiments

There are three different guarantees to consider: execute authorized operations against the correct target, preserve an exact source, and make justified statements. Existing deterministic target/identity checks provide the first; they do not imply the other two. No single “add deterministic checks” proposal is concrete enough until it specifies how the independent truth is obtained.

| Option                                                   | What it could improve                                                                              | Tradeoff / limitation                                                                                                                               | Evidence needed before selecting it                                                                                                                      |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Shorter, task-focused prompting and one concise answer   | Reduces instruction competition and repeated status claims; smallest reversible experiment         | Exact-preservation and unknown-status instructions are already present; another paragraph may worsen density                                        | Compare current versus shorter prompts on synthetic paraphrase/format variants at fixed route, with both quality and latency measured                    |
| Change timeout/recovery thresholds or fallback selection | Reduces abandoned correct work or avoids weaker synthesis routes                                   | May worsen latency and availability; original cancelled completions are unknown; endpoint and model effects are confounded                          | Matched route/recovery experiments; do not infer counterfactual success by subtracting failed-attempt time                                               |
| Independent review for exact-source creates              | Can catch content omitted before storage using existing review infrastructure                      | Adds latency/cost to currently simple writes; reviewer can also approve a mismatch; must not trigger on every harmless create                       | Replay synthetic malformed/valid proposals through the review contract and measure recall, false rejects, and overhead                                   |
| Authoritative exact-source transfer                      | Removes generative copying for explicit verbatim capture                                           | General user prose does not provide unambiguous boundaries; markup/Unicode/newline expectations need a contract                                     | Use immutable original message/attachment spans, source ID plus offsets, and independent digest; test extraction ambiguity and formatting rules          |
| Structured availability calculator or validator          | Interval duration, range, overlap, and buffer arithmetic become deterministic                      | Natural-language constraint extraction and complete source/time coverage still require care; free-form final prose can contradict a valid structure | Synthetic interval property tests plus faithful rendering of returned slot IDs/intervals; include DST, all-day events and adjacent-window events         |
| Evidence-qualified status rendering                      | Keeps “record state” separate from real-world event status; reduces repeated unsupported negatives | Evidence existence and meaning cannot be proved by a regex or a model-supplied label; domain coverage is open-ended                                 | Structured claims with actual source refs, bounded checked scope, and unknown defaults; test explicit yes/no evidence, stale states and partial searches |
| A final semantic review                                  | Can catch both calendar and status contradictions                                                  | Another model pass adds latency; correlated failure and judge calibration remain; a `final_response`-only hook misses these two acting answers      | Test all answer-emission paths and measure added cost/tail latency before broad deployment                                                               |

For exact text, a hash computed from the acting model's own rewritten `content` only proves that the same rewritten text was saved. It cannot establish fidelity to the user. The comparison must derive from the authenticated original source independently. Likewise, a general regex that rejects “No work started” cannot distinguish an unsupported conclusion from explicit recorded site evidence or a quotation; using it as a universal product validator would create false positives. A structured status renderer can guarantee phrasing around a trusted evidence classification, but cannot by itself guarantee that classification is true.

Calendar math is the strongest deterministic opportunity because the user supplies numeric constraints and tools return typed intervals. Even there, validating only the three strings the model selected is incomplete if extraction drops a constraint or the response prose changes the times afterward. A narrow calculator should consume a time window, duration, buffer, and normalized busy intervals; produce or validate concrete intervals; and render the same validated values. Queries must include enough time before and after the target window to evaluate buffers against adjacent events, plus complete pagination/source coverage. The present fixture's lone mid-window event does not test these boundaries.
