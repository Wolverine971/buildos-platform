# Archived: `thoughts/` research trees

<!-- doc-status: archived -->

> **Archived 2026-08-19.** Historical record only. Do not treat anything here as current.

`thoughts/` (repo root) and `apps/web/thoughts/` were the research-document homes
mandated by the October 2025 documentation guidelines. Both stopped receiving new
work in July 2026; research now lives in `docs/research/` and `docs/plans/`.

They were moved here rather than deleted because the analysis is still occasionally
useful as history. They are excluded from `pnpm check:doc-health` and should be
excluded from any search for how the system currently behaves — most of these
documents cite file paths and database tables that no longer exist.

- `root/` — former `thoughts/`
- `apps-web/` — former `apps/web/thoughts/`
